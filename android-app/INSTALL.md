# Franmotest 1.1.7 安卓版安装说明

[下载安卓 APK](https://github.com/Alain-0721/french-vocabulary-test/releases/download/v1.1.7/Franmotest-1.1.7-Android.apk)

在安卓手机打开下载的 APK，按系统提示允许当前下载工具或文件管理器安装应用。安装完成后直接点击 **Franmotest** 图标。

## 直接在 App 内学习

本版自带学习界面和 Édito B1、Inspire A1、Édito A2、Édito A1 四本完整词库，不需要打开或安装 Chrome 等外部浏览器。首次打开即使没有网络，也能进行课本词汇检测。最低支持 Android 6.0。

首页、课本过关、每日检测、词库统计、设置都在 App 内运行。学习记录保存在 App 自己的数据空间；一键导入词库、头像选择和备份导入使用安卓文件选择器，导出备份或模板使用系统保存窗口。每日检测仍需先过关至少四个 Part。

账号登录、注册、头像上传和云端同步需要联网，使用原网站的同一账号。有效会话可在下次打开时自动恢复；离线时使用已保存的本机账号记录，联网后验证并同步。

## 从旧版或网站迁移

- **已有账号**：账号与记录已迁到新服务，原账号首次登录需点击“忘记密码”，用原邮箱设置新密码；不要重新注册。更新前请先确保原版已同步并导出完整备份。
- **游客记录**：先在原网站或旧版 App 的“设置与备份”导出完整备份，再在新版导入。旧版使用的浏览器存储与新版 App 存储分别保存，不会自动搬迁。
- **已安装旧版 APK**：新版保持同一包名和发布签名，版本名为 1.1.7、内部版本号为 10，可覆盖安装。不要为了更新先卸载；卸载或清除 App 数据会移除尚未同步的本机记录。

## 更新和下载

[GitHub Release](https://github.com/Alain-0721/french-vocabulary-test/releases/tag/v1.1.7) 提供 APK、安装说明与 SHA-256 校验文件。学习界面与内置词库随 APK 更新，网页版更新不会自动替换 APK 内置界面。以后下载安装新版 APK 覆盖即可。

App 使用安卓系统内置 WebView 显示随安装包附带的页面，无浏览器地址栏，也不使用浏览器打开学习页面。教程中的“下载文件”、项目 GitHub 等外部链接仅在主动点击时打开对应应用。

## App 内检查更新（1.1.1 起）

设置 → App 更新 → 检查更新；发现新版本后点击“下载并更新”。首页顶部也会自动提示新版。更新包在 App 内下载，校验完整性、包名、版本与发布签名后打开安卓安装窗口。首次请按系统提示允许 Franmotest 安装应用，返回后继续确认安装。取消安装可稍后继续，不需要先卸载。

1.1.3 起更新清单改由 GitHub 提供，不再依赖 Netlify。旧版更新地址已内置，1.1.3 之前的版本需手动下载最新版覆盖安装；1.1.3 及以后可在 App 中检查更新。

## 邮箱验证码找回密码（1.1.4 起）

在登录窗口选择“忘记密码”，输入注册邮箱，填写邮件中的 6 位验证码，再设置新密码。验证码 10 分钟内有效，60 秒后可重发；请使用最新验证码。新密码至少 8 位，可以与旧密码相同。原账号及学习记录保留，整个流程可在 App 内完成。

## 选择菜单与词库切换（1.1.5 起）

顺序和布局的选项在对应按钮下方展开，点选、再次点击按钮、点击外部或按安卓返回键即可收起。Part 和主题使用站内底部选择菜单；Part 直接滚动选择，主题长列表可搜索。词库统计选中 Part 或主题后，列表底部显示对应的前后切换按钮；切换 Part 时显示新 Part 的全部主题，首尾按钮禁用。

1.1.6：Part 选择菜单不显示搜索框，直接滚动选择，不自动弹出手机键盘。

1.1.7：顺序和布局改为就地下拉；新增 Édito A1 2022，10 个单元、20 个 Part、80 个主题组、566 条词条，全部音标仍待校对。四本课本的进度与逐词统计独立保留。
