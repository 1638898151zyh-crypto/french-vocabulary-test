# Franmotest 1.0 安卓版安装说明

下载 `Franmotest-1.0-Android.apk` 后，在安卓手机打开文件，按系统提示允许当前浏览器或文件管理器安装应用，再完成安装。首次打开请保持联网。

应用显示名称为 **Franmotest**，使用圆形启动图标。进入首页，选择“我的课本”，即可开始课本过关、每日检测与词库统计。

## 运行环境

- Android 6.0 或更新版本。
- 安装并启用支持 Trusted Web Activity 的浏览器，例如 Chrome。建议使用浏览器支持的最新版本。
- 浏览器验证 App 与网站关联后，学习页面以独立应用窗口打开；不支持此模式的浏览器会使用带地址栏的浏览窗口。

## 学习记录与离线使用

应用访问 https://franmotest.netlify.app/，继续使用现有网站功能。使用同一浏览器时可沿用该浏览器里的账号和本机记录；如果浏览器不同，请登录账号同步，或从原浏览器的设置中导出完整备份，再在 App 中导入。

首次联网打开，等待“离线词库已准备好”后，可离线检测并保存本机记录。账号验证、云端同步及新词库下载需要联网。网站更新会提示“更新并重新打开”，确认后启用新版本。

## 更新与下载

安装包下载页：https://github.com/Alain-0721/french-vocabulary-test/releases/tag/v1.0

以后安装新版 APK 时，直接覆盖安装即可。请保留学习备份，避免因清除浏览器数据或更换浏览器而丢失未同步的记录。签名密钥保持不变时，后续 APK 可覆盖升级。

`Franmotest-Android-SHA256SUMS.txt` 提供文件 SHA-256 校验值。
