# 多课本选择：第一版设计

本文件记录设计提案。正式入口、存储和云端同步尚未修改。

> 本文保留设计与开发过程，早期章节描述的是当时的预览状态。2026-10-06 已接入并发布正式网站；当前使用和保存规则以 [README.md](README.md) 为准。

## 预览入口

- Vite 开发服务中的 `/textbooks-preview.html`。
- 初始为“我的课本”书架；可以点击卡片或右上角的当前课本菜单切换。
- 检测进度仅在页面内存中。导入词库使用独立的 `atelier:design-imports:v1` 键；不访问原有学习记录、Identity 或 `/api/progress`。
- Édito B1 使用仓库现有 1110 条词库；所有评分和过关都是临时演示状态。
- Inspire A1 已接入用户提供的完整 CSV，937 条词汇与表达、8 个单元、32 个 Part、180 个主题。书架直接可选，刷新仍保留词库；全部音标保留人工转写待独立复核状态。
- “我的法语笔记”包含 6 条非教材演示词，用于体验另一本课本的独立进度。
- Édito A2 2022 第 2 版已接入 850 条词汇；Édito B2 仍是待确认版本和词库的占位选项。

## 页面与交互

1. 新增“我的课本”书架，展示名称、级别、版本、词库状态及本书进度。
2. 页面顶部保留“当前课本”切换入口，不必每次回到书架。
3. 切换课本时，检测、每日复习、词库和记录同步切换到所选课本。
4. 没有词库的课本可以查看信息，页面说明下一步需要添加词库，不显示伪造词数或检测题。
5. 可直接“一键导入词库”，或先添加待接入课本信息，再导入对应的文件。
6. 每本课本的主进度、每日练习、累计与历史分别保留；切换不等于重置。
7. 单 Part 全主题分组、新 Part 独立卡片、评分可改选等既有行为继续保留。
8. 手机以底部导航和两列课本卡片展示；顶部仍能切换课本。

## 正式实现时的数据边界

- 用稳定的 `bookId` 区分课本和版本，例如 `edito-b1-2023`，而不是只用级别。
- 现有词条 ID 保持不变。课本词库、累计及进度按 `bookId` 隔离，避免不同教材都含 `U1P1` 时混用记录。
- 每本课本独立保存现有学习 bundle，外层增加选中课本与课本集合。
- 旧版 Édito B1 的学习记录无损迁移到它对应的课本空间，不从零开始。
- 导入文件需要识别或确认目标课本；不把未知教材备份自动归入 Édito B1。
- 每日复习只读取所选课本的正式已过关范围。B1 现有 4 Part、5×10、单主题规则保持；其他教材按实际章节与词库另行定义条件，不盲目套用。
- 云端格式校验和备份格式需一起升级；完成真实账号验收后再声称支持多课本跨设备同步。

## 一键导入与生成教程

- 入口：我的课本、一张待添加词库的课本详情、`#/guide` 教程。
- 支持未加密 `.xlsx`、UTF-8 `.csv`、平面词条数组 `.json`，每文件 8 MB / 10,000 词。
- 格式参考用户的 `Édito_B1_2023_标准词库.xlsx` 中“完整词库”A4:N4 的 14 列；前 30 行识别表头，忽略其他说明/抽题规则表。
- 必填 ID、Unité、Partie、主题、法语与中文；校验重复/危险 ID、必填项、正整数字段、文本长度及同 Part 标题。保留来源和 IPA 校核状态。
- 检查后展示词数/章节数/主题数、前三条样例和建议核对项，确认后才改变课本集合。相同词库打开已有课本，不覆盖进度；不同教材的同名 ID 按课本隔离。
- 可创建新课本或填充待接入课本；识别级别与目标课本不一致时阻止导入。正式已就绪的课本不提供覆盖入口。
- 勾选记住只保存词库到当前浏览器，最多 30 本。保存失败时不改变课本集合，可取消勾选临时使用；损坏的旧缓存保留，不自动覆盖。
- 教程提供五步流程、14 列字段说明、完整可复制 AI 提示词、空白 CSV 模板和 Markdown 教程下载。AI 提取不调用网站 API。
- 当前仍为单独设计预览，未接入生产入口、正式备份、登录同步和每日复习。重置预览保留已导入词库，仅重置内存检测进度。
- 验证：`npm run test:import -- <标准词库路径>`；标准附件识别为 1110 词、12 单元、24 Part、129 个按 Part/名称合并的主题，1046 条音标待核对。原件未修改。

- 来源为用户提供的 `Inspire_A1_标准词库.csv`；说明文件仅作数据解释，不执行其中关于默认筛选或每日抽题的提议。完整保留 P1–P4，包括整句表达。
- 接入 `assets/inspire-a1-bank.json` 和 `src/supplied-books.js`，课本 ID 为 `inspire-a1`。未给出教材出版版本，不将说明文件日期当作教材年份。
- 修复 17 列兼容：`lemma_in_book` 与 `original` 分开保留，保留 `partie_id` 与 `entry_in_group`，按数值章节、主题及组内序号排列，词条 ID 不重生成。

- 每本书独立检测状态；Édito 与 Inspire 同名 ID 互不覆盖。网站正式入口与正式记录保持不变。

## Édito A2 2022 导入

- 来源：用户提供的 `Édito_A2_2022_标准词库.csv`，850 条词汇、12 个单元、24 个 Part、110 个主题组。词库说明作为来源解释，不执行其中的抽题或发音判分建议。
- 新课本使用独立版本 ID `edito-a2-2022`，替换原 A2 占位项；其他用户导入的课本与浏览器缓存不覆盖。
- 原始 17 列保存在 `assets/edito-a2-2022-bank.json`；中文标题另存 `assets/edito-a2-2022-titles.json`，按章节上下文区分“设备”“人物”等重名主题。
- 保留 807 条 `manual_draft_review_needed`、41 条 `espeak_draft_review_needed` 与 2 条 `manually_reviewed`。仅保留来源标记，不宣称完成新的语音复核。
- 接入范围仍是本地多课本预览，不修改正式 Édito B1 学习记录。
- 直接学习链接：`/textbooks-preview.html?book=edito-a2-2022#/study`。

## 检测交互更新（2026-10-05）

- 整行点击翻词；对错按钮只负责自评。隐藏答案和音标保留布局空间，翻开与收起不移动单词或后续行。
- 法语完整展示优先，不截断长表达；音标放不下时自动移至下一行靠右。两种布局分别为对错左/翻译右、翻译左/对错右，单元格内容顶部对齐。
- 检测页底部目录直接选择任意 Part，不跳转词库页；未完成轮次可恢复，已过关 Part 可再次检测。移除独立旧卡片栏。
- 新的预览检测状态由 `src/preview-study.js` 管理，正式网站和插件的检测引擎及学习存储不变。每本书各自保存选中 Part、过关集合、轮次和词条累计次数。
- 任选 Part 只过关当前部分，不隐含前面全部已过关。手动过关或全部正确后自动选择下一个未过关部分；整书完成仍可重测。
- 每词每轮只计一次当前判定：重复同一按钮不增加次数，改选扣除旧判定并增加新判定，新一轮累计新次数。之后重测错误不会清除先前过关标记。
- “记录”点击 Part 展开所有词的正确/错误次数，包括未自评的零次词条。
- `#/settings` 保存布局和主题内乱序偏好到独立 `atelier:design-settings:v1`；默认不乱序。改变设置不重排现有卡片，仅新卡片或重测应用，主题之间不混合。
- `#/about` 提供网站介绍、六步使用教程和原词库生成教程入口。每日复习仍为占位；检测统计在本次预览会话中保留，刷新后重置，界面明确说明。
- 检查：`npm run test:study` 验证任选 Part、重测、累计与改选、自动过关、整书完成后重测、主题内乱序及课本隔离；浏览器检查两种布局、整行点击、逐词统计和手机长表达，并测量翻词前后位置。

## 与原站内容衔接及导航调整（2026-10-05）

- 核对 `https://editob1test.netlify.app/` 的公开页面和入口资源，保留首页、课本、每日检测、普通检测、完整词库、记录以及设置与备份的内容位置。
- 主要导航和手机底栏严格为：首页、课本过关、每日检测、词库统计、设置。书架由首页、顶部课本切换器和侧边当前课本卡进入；旧 `#/books` 链接继续有效。
- 默认首页为 `#/home`，恢复原站法语欢迎区、当前课本进度、两种主要检测入口、普通词汇快捷入口与累计活动摘要，随当前教材变化。
- 教程从首页和设置进入，不占主导航栏位置。词库生成教程仍支持 `#/guide`，网站介绍与八步使用教程支持 `#/about`。
- “词库统计”包含完整词库和学习记录两个选项，支持法中搜索、Part/主题筛选、教材页码、来源和音标状态，分页继续加载全部匹配词条；`#/records`、`#/dictionary` 旧入口仍有效并选中词库统计导航。
- 恢复每日检测五组十词：按当前课本真实过关集合排序，最近过关 Part 两组、前两个各一组、其余过关 Part 一组；每组取单个主题，主题词数不足时明确提示，绝不借用未过关词条。进入或换日重新生成，不改变主进度。
- 普通词汇检测从首页进入。B1 继续使用原站第一单元 P1＋P2 的 94 词库与原算法；其他教材仅在第一单元两部分分别足够 25 词时启用。每日与普通检测各自累计、可重测，并保留最近 20 轮供统计页查看。
- 设置与备份恢复账号与保存、进度备份与迁移、浅色/深色/跟随系统、关于词库；同时保留新增卡片布局与组内乱序。外观只保存至 `atelier:design-theme:v1`，不修改正式站的 `edito-theme`。
- 预览支持完整多课本备份以及本书主进度文件导出导入。恢复前检查词库、词条 ID、轮次、计数和复习历史并展示确认界面，错误文件不修改状态。内置词库不能通过备份覆盖。
- 原站 `atelier` 完整备份和插件 `textbook` 主进度可只迁移 B1 主进度到预览新结构，保留词条计数；预览文件不宣称兼容旧站反向导入。预览不会读取或修改正式学习缓存或写云端数据，账号与同步入口链接正式站设置页。
- 检测数据仍是页面内存记录，刷新前可手动备份恢复；账号云端同步保持原站处理。这一节替代此前“每日复习仍为占位”的描述，未部署正式站。
- 验证：`npm run test:navigation` 检查复习与主进度隔离、完整/单书备份往返、历史保留、非法数据拒绝、旧站进度迁移与内置词库保护；浏览器验收五项导航、手机布局、词库筛选及备份下载/恢复全流程。

## 头像菜单与保持登录（2026-10-05）

- 首页检测与练习区后依次展示“我的课本进度”和整张可点击的大型“我的课本”卡片，显示真实书架数量、可检测数量与三本课本的概念封面，直接进入 `#/books`。
- 共享 `AccountMenu` 用于正式入口和多课本预览。登录后点击右上角头像打开切换账号、设置、退出登录三个菜单项；退出使用红色底色与边框。支持方向键、Esc、Tab 和点击外部关闭。
- 正式入口切换账号直接显示另一账号的登录表单，验证成功后才更换会话；取消或验证失败保留旧账号。退出调用现有 Identity SDK，恢复原游客学习空间，不清理各账号的学习缓存。
- 继续使用 `@netlify/identity` 的默认持久会话。安装版本的浏览器 Cookie 原为 session-only，`identity-session.js` 将已由 SDK 建立的访问 Cookie 保留至令牌自身到期、刷新 Cookie 保留最多 30 天，保持 Secure / SameSite=Lax / Path=/。不额外保存密码，也不以本地布尔标记代替登录。
- 页面启动先调用 SDK `refreshSession`，再 `getUser`，避免过期访问 Cookie 导致 SDK 提前清除可续期会话。登录、回调和令牌续期事件更新 Cookie 有效期；登出沿用 SDK 的会话清除操作。过期或撤销的刷新凭证仍需要重新登录。
- 本地多课本页仅使用标注“演示账号”的头像交互，不收集密码或修改正式账号。正式入口登录代码已更新但尚未部署；Netlify Identity 的真实会话必须在线上环境验收。
- 验证：`npm run test:account` 检查持久 Cookie 有效期、浏览器重建后的保留、续期/查用户顺序、无效会话拒绝，以及正式 App 在 SDK mock 下自动恢复、切换失败/取消、成功切换和登出。原站 27 项检查、类型检查继续通过；浏览器检查桌面和 320/390/768px 菜单与大卡片。
